# 運用ダッシュボード デザインシステム（方向3「計器」＋方向2「盤」）

決定: 方向3を主画面、方向2の盤を「銘柄」ページの表示切替に採用（比較は `docs/ui_directions/DIRECTIONS.md`）。
実装は `apps/web/ops.html`。**CLAUDE.md の境界は変えない**: 読み取り専用、外部読み込みなし（CSP）、データは `textContent` のみ。

## 1. 原則
1. 最初の1画面で「正常か／お金は／何を持っているか」に答える。
2. 計画（損切り〜目標）は**図で**見せる。数字だけにしない。
3. 色だけで伝えない（符号・▲▼・文字を併記）。
4. 装飾しない。動きは状態変化の説明にだけ使う。

## 2. カラートークン
| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#eff1ec` | ページ背景（灰緑の生成り） |
| `--panel` | `#f9faf7` | 面 |
| `--ink` | `#15201b` | 本文・太線（墨緑） |
| `--mute` | `#5a665f` | 補助文字（背景比 4.5:1 以上） |
| `--line` | `#d5dad2` | 罫線 |
| `--acc` | `#d99a00` | 注意・現在地（サフラン） |
| `--up` | `#0e7a55` | 利益（緑）。白文字との比 5:1 以上 |
| `--dn` | `#c0392b` | 損失（赤）。白文字との比 5:1 以上 |
| `--flat` | `#5a665f` | 損益ゼロ |

- 紫〜青のグラデーションは使わない。グラデーションは使わず、単色。
- **盤のウィンドウは二値**: 利益>0 は緑、損失<0 は赤、0 は灰。濃淡で量は変えない（量は文字で読む）。
- 状態の線: 正常=緑、注意=サフラン、停止/要確認=赤。

## 3. タイポグラフィ（外部フォント不可 → システムフォント）
- 本文: `"Hiragino Sans","Noto Sans JP",system-ui`、16px、行間 1.6。
- 数字: `ui-monospace,"SF Mono",Menlo,Consolas`＋`tabular-nums`（桁が揃う）。
- 大きさ: 資産 40px／副数字 22px／銘柄コード 17px 太字／補助 12〜13px（本文は12px未満にしない）。

## 4. 余白・グリッド
- 基準 4px の倍数（8/12/16/24）。ページ余白 PC 24px・スマホ 16px。
- PC: 左レール 230px（今日の流れ）＋本文（最大 1100px）。タブレット: レールが上に回る。スマホ: 1カラム、下タブ。
- 盤: `repeat(auto-fill,minmax(150px,1fr))`、各ウィンドウは**同じ高さ**（132px）。

## 5. 形・影・境界
- 角丸は小さく（銘柄ウィンドウ 6px、パネルは角丸なし＋罫線）。影は使わない。区切りは 1px 罫線と 2px の墨線。
- 銘柄ウィンドウ: 上に細いタイトルバー（コード・▲▼）、本文に損益％、下に会社名と割合。
- 「すべて同じ角丸カード」にしない: 主画面は**罫線で区切った行**、盤だけが面（ウィンドウ）。

## 6. 部品
- **範囲ゲージ（Bullet）**: 左＝損切り、右＝目標。太い黒線＝いまの価格、細い灰線＝買値、赤みの帯＝損切りまでの距離。損切りまで 6% 未満は黒線を赤にして「損切り近い」を併記。
- **今日の流れ**: 縦タイムライン（実行→候補と約定→口座の保存→次回）。実データのみ。
- **タブ**: 今日／銘柄／詳細。PC は上部、スマホは下部固定。
- **詳細シート**: 銘柄を押すと開く。理由・計画・やめる条件。

## 7. 動き
- 変化の説明だけ: タブ切替なし、シートの開閉 120ms のフェード、ゲージは動かさない。
- `prefers-reduced-motion` ではすべて 0ms。

## 8. アクセシビリティ
- 文字のコントラスト 4.5:1 以上（大きい文字 3:1）。損益は色＋符号＋▲▼。
- キーボード: すべて Tab で到達、フォーカスは 3px の墨線、Esc でシートを閉じる、ウィンドウは `button`。
- タッチ: 押せる要素は 44px 以上。
- **盤は補助**: 「表」表示（ゲージ付きの行）を同じ画面で切り替えられる。盤の各ウィンドウに `aria-label`（銘柄・損益・割合）。
- `lang="ja"`、見出し階層を守る。`role="dialog"` と `aria-modal` を詳細シートに付ける。

## 9. 端末別
| 幅 | 構成 |
|---|---|
| ≥ 1000px | 左レール＋本文、盤は 6〜7 列 |
| 760〜1000px | レールは上に回り横並び、盤 4〜5 列 |
| < 760px | 1カラム、下タブ、盤 2 列、ゲージは行の下段に全幅 |

## 10. 表示速度
- 外部リクエストなし、画像なし、1ファイル。30秒ごとの更新は差し替えのみ。
