### 利用者と主要業務
- 利用者は運用者1人（日本在住、スマホとPC）。技術者ではなく、毎日数十秒で「正常か／お金は／何を持っているか」を確かめたい。
- 異常時だけ深く見る。操作はしない（読み取り専用）。
- 画面の核は2つ: **安全の確認**と、**銘柄ごとの「持つ理由と計画」**（損切り・目標・撤退条件）。
- 既存の制約: 外部フォントや外部スクリプトは不可（CSP）、データは `textContent` のみで描画、API は変更しない。

### 抽出したパターン（模倣ではなく要素の抽出）
| 出典の型 | 抽出する要素 | 持ち込まない要素 |
|---|---|---|
| 新聞・日報 | 一文の見出しで状況を言い切る、罫線で区切る、等幅でない数字 | 装飾的な飾り罫 |
| 株式のヒートマップ（面積＝大きさ、色＝騰落） | 全体を1枚で俯瞰、大きいものが目立つ | 数十〜数百銘柄前提の密度 |
| 計器盤・レンジ表示（52週レンジ型） | 「範囲のどこにいるか」を1本の線で示す | 多色のゲージ |
| 運用コンソール（監視ツールの状態バー） | 常に一行の状態バー、異常時のみ色が出る | 情報の詰め込み |

### UI UX Pro Max による照合（`--design-system` と `--domain chart/ux`）
- **全体提案**は「ダーク（OLED）＋ Fira Code/Fira Sans ＋緑アクセント」。ただし「パターン」は*ランディングページ用*（Enterprise Gateway）で、運用画面には当てはまらないため採用しない。Fira は Google Fonts の外部読み込みで、**このアプリの CSP（外部読み込み不可）に反する**ため、等幅・ゴシックともシステムフォントで代替する。
- **チャート選定**:
  - 「位置が範囲のどこにあるか」は **Bullet Chart**（目標を黒線で示す）が該当。アクセシビリティ risk:low、3〜10個を並べる用途に最適。これは方向3の「損切り〜目標の線」と同じ型で、**方向3を裏づける**。
  - **Treemap** は risk:high。「色だけに頼らず、ツリー表（リスト）を主たる読み方にし、盤は補助にする」ことを要求。「セルが20未満なら棒を使う」とも書かれており、10銘柄前後の現状では盤は**必須ではなく補助**が妥当。
- **UXルール**: 「色だけで情報を伝えない」（High）。見本は +/- の符号と文字を併記しているが、方向2の盤は色の比重が高く、符号の併記と表の併設が要る。

### 現行UIの課題（再掲）
同じ重みのカードの羅列／色が青系に偏り個性がない／銘柄の「計画」が文字でしか読めず、危険度が一目で分からない。

## Phase 2: 3つの方向

| | 方向1「夕刊」 | 方向2「盤面」 | 方向3「計器」 |
|---|---|---|---|
| 一言 | 新聞の一面のように読む | 持ち株を1枚の盤で俯瞰する | 損切り〜目標の線で計画を見る |
| レイアウト | 1カラムの紙面。見出し→数字帯→注目枠→全銘柄（2段組） | 左レール＋上部状態バー。中央に面積比例の盤、右に詳細パネル | 左に「今日の流れ」の縦タイムライン、右に銘柄の行（線グラフ付き） |
| タイポグラフィ | 明朝系の大見出し＋ゴシックの注記 | ゴシックのみ。数字を大きく、ラベルは小さく | 等幅の数字（桁が揃う）＋ゴシック |
| 配色 | 生成り地・墨・朱（損）・松葉色（益） | 炭色地・砂色アクセント・レンガ色／苔色（損益） | 薄い灰緑地・墨緑・サフラン（注意）・赤／緑 |
| ナビ | 上部の文字タブ（下線） | PC: 左レール ／ スマホ: 下タブ | PC: 左レール（流れ）＋上部 ／ スマホ: 下タブ |
| 個性の核 | 読み物としての安心感 | 「どれが大きく、どれが赤いか」が一瞬で分かる | 計画（損切り・目標）を**図で**見せる唯一の案 |

### メリット・デメリット
**方向1 夕刊**
- 良い点: 一番やさしい。言葉で状況を言い切るので迷わない。印刷物のような落ち着き。スマホでも崩れにくい。
- 悪い点: 銘柄が増えると縦に長い。損益の大小が数字でしか比べられない。計画は開かないと見えない。

**方向2 盤面**
- 良い点: 要望の「ざっと俯瞰」に最も合う。大きく持っている物・赤い物が瞬時に分かる。ダークで常時表示に向く。
- 悪い点: 銘柄が多い（30超）と小さな枠が読めなくなる。色の濃淡は微差を伝えにくい。スクリーンリーダーに向かないので、別途リスト表示が要る。

**方向3 計器**
- 良い点: このシステムの核である「買う前に決めた計画」がそのまま見える。損切りに近い銘柄が線の位置で分かる。等幅数字で比べやすい。スマホでも1銘柄=1行で読める。
- 悪い点: 3案で最も情報が密。初見で線の読み方に説明が要る（凡例を付けている）。純粋な「俯瞰」は盤面に劣る。

### 私の推奨（スキルの照合を反映して更新）
**方向3「計器」を主画面にする**ことを推奨します。方向2の盤は、銘柄が20を超えたときの「全ての銘柄」ページの*補助表示*（表を主とし、盤は切替）に留めます。
- 理由1: 「なぜ持つか・今後の計画」という最大の関心事を、図で見せられるのは3だけ。
- 理由2: 俯瞰が必要な場面（銘柄が増えたとき）は、盤の面積表示が最も強い。
- 懸念: 2案を混ぜると統一感が崩れやすい。色と書体は3に合わせ、盤は同じ配色で作り直す前提です。
- 迷う場合の単独推奨: 銘柄数が10〜15で続くなら3、30を超える見込みなら2。
